=== SUIVI KNATUROPATHY ===
Dernière mise à jour: 2026-08-11
Projet: KNaturopathy (Expo + Node backend + Mistral API)

--- ARCHITECTURE ---
- Frontend: React Native (Expo Go) → ~/Desktop/KNaturopathy/
- Backend: Node.js sur Render → https://knaturopathy-backend.onrender.com
- IA: Mistral API (open-mistral-nemo) via variable MISTRAL_API_KEY
- Base de données: SQLite (98 plantes) dans backend/data/database.db
